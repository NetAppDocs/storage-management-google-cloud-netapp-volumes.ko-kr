= Google Cloud NetApp Volumes 빠른 시작
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
NetApp Console 역할을 할당하고, 자격 증명을 추가하고, 시스템을 검색하여 Google Cloud NetApp Volumes를 시작하십시오.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-1.png["하나"] link:task-add-roles.html["역할 할당"]
[role="quick-margin-para"]
NetApp Console 에서 멤버에게 올바른 역할을 할당합니다.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-2.png["둘"] link:https://docs.netapp.com/us-en/data-services-workloads/gcnv/add-credentials.html["자격 증명 추가"]
[role="quick-margin-para"]
NetApp Console에서 Google Cloud NetApp Volumes 자격 증명을 추가합니다.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-3.png["삼"] link:task-create-system.html["시스템 추가"]
[role="quick-margin-para"]
NetApp Console에서 자격 증명, Google Cloud 프로젝트 및 지원되는 지역을 사용하여 시스템을 검색합니다.
